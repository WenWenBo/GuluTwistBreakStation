# 咕嘟扭扭使用说明

## 安装与第一次打开

macOS 15+：解压与你的芯片对应的 ZIP，将 **GuluTwist Break Station.app** 拖到“应用程序”，双击打开。Apple Silicon 用 `aarch64`，Intel 用 `x86_64`。当前包为个人 ad-hoc 签名，未经过 Apple 公证；如果系统拦截，请先核对来源，再由你在系统“隐私与安全性”中决定是否允许打开。无需安装 Rust。

Windows 10／11 x64：在 Windows 上构建完成后，运行 `GuluTwist-0.1.0-Windows-x64-Setup.exe`，安装到当前用户目录，无需管理员权限。也可解压便携 ZIP。当前仓库尚未在 Windows 真机生成和验证安装包。

第一次打开，在“提醒设置”里选择事项、星期、工作时段和提醒模式。默认配置：

| 事项 | 每隔 | 默认方式 | 全屏时长 |
| --- | --- | --- | --- |
| 咕嘟喝水 | 30 分钟 | 轻提醒 | 30 秒 |
| 扭扭颈肩 | 40 分钟 | 轻提醒 | 60 秒 |
| 如厕放风 | 90 分钟 | 轻提醒 | 180 秒 |
| 站立活动 | 60 分钟 | 轻提醒 | 120 秒 |
| 保护眼睛 | 20 分钟 | 全屏休息 | 20 秒 |

默认星期一至星期五，09:00–12:00、13:00–18:00。每项独立选择「轻提醒／全屏休息」，护眼也能改成轻提醒。先点“体验 5 秒休息”，默认可点击底部灰色文字“退出”提前结束；体验遵循已保存的退出选项，不产生记录。点击“确认，开始照顾自己”并保存成功后才启用正式提醒，主窗口会自动收起到菜单栏／系统托盘。保存失败或常驻图标不可用时保留窗口。

只有选择全屏休息时才显示时长；切回轻提醒会保留原时长。设置的休息时长分成「分」「秒」填写，例如 1 分 30 秒；总范围 5 秒–30 分钟，秒字段 0–59。保存 / 取消固定在页面底部。未保存时切换页面会让你选择保存、放弃或继续编辑。


间隔、休息分钟和秒数只接受数字 `0–9`。可以清空后重填；含中文、空格、小数点或换行的粘贴会整次拒绝，保留原值。失焦后去掉前导零，越界或空值不能保存，不会自动改成上下限。

工作时段使用小时／分钟分段控件，可直接输入数字、用方向键调整和切换分段，无需输入冒号。结束时间勾选“至当天结束”表示 `24:00`；取消后恢复本次普通结束时间，旧全天配置首次取消时显示 `23:59`。开始须早于结束，跨午夜请拆成两个时段。

“提醒设置 → 全屏休息”新增“隐藏退出全屏按钮”，默认未勾选。勾选并保存后，下一场正式休息或 5 秒体验中不显示“退出”按钮，计时结束后自动关闭。未保存草稿不影响体验，本场权限不会中途改变。取消勾选并保存后，下一场恢复可退出；全局暂停、退出应用与工作时段结束仍按原规则处理。

## 日常操作

- **强制休息**：到期覆盖全部活动显示器，仅合并同批全屏事项，取最长休息时长；已有轻提醒暂时隐藏，结束后恢复。倒计时结束自动撤下。允许提前结束时，点击任意屏幕底部的灰色文字按钮“退出”，不退出应用；Esc、返回键和关闭窗口均不会结束本次休息。
- **轻提醒**：到期在胶囊下方出现提醒条，点击右侧圆形勾选即完成并重新开始本项计时。多项逐条显示，同项不重复堆积；未完成会一直保留到当前工作时段结束或退出应用。首页仍可完成、稍后 5/10/15 分钟或跳过。护眼选轻提醒时也可直接勾选，不强制等待 20 秒。
- **主动完成**：首页点击某项“我已完成”，记为手动完成并重置该项间隔；强制休息中不能提前完成。
- **修改方式**：在提醒设置中为单项选择方式并保存。当前已到期实例保持原方式，新方式从下一次提醒生效。
- **暂停**：窗口右上角「暂停提醒」菜单或托盘提供 15 分钟、1 小时、下一工作日、手动暂停，同一工作时段内恢复后轻提醒待办重新显示。到下一工作日指下一个选中的星期日期，非当天午休后。
- **后台运行**：关闭主窗口一次即隐藏，应用继续提醒，未保存的设置草稿仍保留。菜单栏 / 托盘可重开。要停止所有提醒，选“退出咕嘟扭扭”。
- **Mac 快捷键**：`⌘W` 关闭主窗口；休息遮罩上按 `⌘W` 不会结束本次休息。`⌘Q` 退出应用并停止提醒。
- **记录**：首页场次与事项次数分开；今日记录列出计时、手动、跳过、中断、未处理和取消。清空全部记录需要二次确认，提醒设置不会清除。

## 胶囊与主窗口怎么切换

胶囊是独立的小窗，可以与主窗口同时显示。它的大小固定为 236 × 52，左侧是小咕图标，中间显示最近事项和倒计时，右侧依次是清单图标和“···”菜单。

| 你想做什么 | 操作 |
| --- | --- |
| 从主窗口进入胶囊日常使用 | 在“提醒设置 → 桌面悬浮窗”开启“显示桌面悬浮窗”，再关闭主窗口 |
| 从胶囊打开主窗口 | 双击胶囊图标或时间（单击不会打开），或点“··· → 打开小站”；胶囊仍保留 |
| 回到只显示胶囊 | 关闭主窗口即可 |
| 只用主窗口 | 关闭设置中的悬浮窗开关，或点胶囊“··· → 隐藏悬浮窗” |
| 隐藏后找回胶囊 | 从菜单栏／托盘选“显示悬浮窗”，也可重新打开设置开关 |
| 调整位置或找回屏幕外的小窗 | 拖动胶囊；或在设置／更多菜单点“重置悬浮窗位置”，回到主屏工作区右下角 |

开启状态和位置会保存。旧版升级默认关闭，首次引导可提前勾选，完成引导后才显示。开关即时保存，不需要点击提醒规则的“保存”，也不会提交尚未保存的提醒规则。保存失败会显示提示并恢复上次已保存的开关；位置保存失败时当前位置本次仍可用，下次拖动或重置可重试。

无论胶囊开关如何，完成引导后的正常冷启动都不弹主窗口，胶囊按开关显示。首次引导、数据异常或托盘不可用时保留主窗口。从菜单栏／托盘选择“打开咕嘟扭扭”“提醒设置”，或再次启动应用，可打开主窗口；已最小化的窗口会还原。休息或锁屏期间的打开请求会等到结束／解锁后执行。隐藏胶囊与关闭主窗口都不暂停提醒；要停止计时，请使用“暂停提醒”或退出应用。

点击清单图标可查看所有启用事项，剩余时间越少的事项越靠近主胶囊：向下展开时从上到下由短到长，向上展开时由长到短；同值从上到下依次为喝水、颈肩、如厕、站立、护眼。每行有独立倒计时，“稍后”使用其剩余时间，“待完成”按剩余时间 0 排在最靠近主胶囊的一侧。点击该行 `✓` 只完成这一项，记一次手动完成并立即开始新一轮；原行短暂显示“已完成”，约 1 秒后恢复倒计时并重新排序，清单保持展开。

再次点击清单图标、按 Esc 或点击外部可收起；清单与更多菜单互斥，拖动时跟随胶囊，底部空间不足时向上展开。展开清单会暂时隐藏独立待办提醒条，收起后恢复未完成项。暂停、下班或全部事项关闭时不可打开；休息、锁屏或隐藏胶囊时自动收起。

胶囊使用相同的提醒引擎，不另算一套时间。暂停时显示“已暂停”，非工作时段显示“下班啦”和下次工作开始时间，全部关闭时显示“提醒未开启”；显示尚未到期的最近事项；已到期内容放在提醒条中，全部待办时显示“全部待处理”。正式休息、体验及锁屏期间临时隐藏，结束后按开关恢复。更多菜单可用方向键选择、Enter 执行、Esc 关闭；Mac 上胶囊自己的 ⌘W 会关闭悬浮开关。

关闭胶囊后，到期仍临时显示独立提醒条，全部处理完即隐藏，不会重新打开胶囊开关。胶囊靠近底部时，提醒条会改放上方。锁屏、睡眠、全屏休息和暂停期间隐藏待办，回到同一工作时段继续显示；午休／下班或退出时清空。

Mac 正常运行时不显示在程序坞和 ⌘Tab 中，设置窗口打开时也是如此（手动固定的静态程序坞图标由系统保留）；Windows 主窗口打开或最小化时显示任务栏／Alt+Tab，关闭后只保留托盘。Windows 托盘左键打开、右键出菜单；图标可能在右下角 ∧ 展开区。胶囊、提醒条和休息遮罩不单独占任务栏。

如果常驻图标不可用，小站会保留主窗口并显示“重试常驻图标”和“退出应用”。Mac 此时临时恢复程序坞入口；重试成功后恢复菜单栏模式。

本轮版本与验收状态见[常驻模式报告](validation/RESIDENT_APP_REPORT.md)。

## 时间怎么算

提醒间隔只累计电脑清醒、未锁屏、工作时段内、未暂停、没有强制休息的时间。离开键鼠不自动暂停。下一工作时段和重新启动从完整间隔开始，不补发退出期间的提醒。

已经开始的休息包含锁屏和睡眠时间；回到电脑时已完成就结束遮罩。解锁、唤醒、休息完成或紧急退出后，新一轮提醒至少等 60 秒有效时间。休息跨出工作时段则取消；若在边界前已经到时则算计时完成。

## 提醒条或通知没出现

轻提醒正常使用独立提醒条，不重复弹系统横幅。请先检查是否处于工作时段、是否暂停或正在全屏休息。若提醒条创建失败，应用会打开主窗口并降级系统通知。

先在设置里发送测试通知，再检查系统通知权限和专注模式。应用显示“已发出”表示提交了请求，不保证系统实际展示。权限状态目前显示未知，完整操作始终可在首页完成。macOS 必须从 `.app` 运行，不能用 `cargo run` 的结果判断通知。

## 本地数据与恢复

SQLite 文件名 `station.sqlite3`，正常位置：

- macOS：`~/Library/Application Support/app.GuluTwist.BreakStation/`
- Windows：`%LOCALAPPDATA%\GuluTwist\BreakStation\data\`

具体目录由 `directories::ProjectDirs` 按平台生成；开发时设置 `GULU_DATA_DIR` 可切换到独立测试目录。备份请先退出应用，再复制整个目录，包含数据库及其附属文件。

记录仅存本机，保留最近 30 个自然日。数据读取失败时提醒暂不启动，可在错误提示中恢复上一份设置或使用默认设置；原文件保留为 `station.sqlite3.recovery-时间戳` 及对应附属文件。恢复会建立新数据库，旧记录仍在备份中，不自动导入新库。

提醒记录写入失败时界面提示“暂未保存”，后台会重试。紧急退出不等待写盘。持续存储故障时强行结束进程可能丢失尚未落盘的记录。

## 更新与卸载

先从托盘退出，再覆盖应用包或安装新版本，数据目录保留。首次升级到本版会把旧四项改为轻提醒，保留自定义间隔、开关、时长和历史记录，追加开启的护眼 20 分钟／20 秒全屏项；之后修改的方式会正常保存。原配置会在数据库中备份，升级后的数据不应直接用旧版打开。卸载 Mac 应用可以将 `.app` 移到废纸篓；Windows 使用开始菜单卸载入口。首版未注册开机启动项。卸载默认保留个人设置和记录；如需清除，退出后由你自行删除上述数据目录。

当前不提供开机启动、声音/主题配置、云同步、后台更新。完整测试范围与尚待验证内容见[本机报告](validation/LOCAL_REPORT.md)。
