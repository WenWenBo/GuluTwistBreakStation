# OTA 实机验收手册

适用：Windows 10/11 x64、macOS 15+ ARM64 / Intel。每个平台独立记录，不以 CI、交叉编译或 Rosetta 代替原生升级。

## 隔离准备

准备两个递增版本 A、B（本机实验为 0.1.1、0.1.2），均使用同一份已确认的实现代码、SDK 和 vpk。测试版本在单独源码副本中修改 Cargo 版本并同步 Cargo.lock，不能直接公开到生产仓库。保持 package ID、OS 身份与各自 channel 不变。

将 A 安装/解压到独立可写路径，将 B 的 `*-full.nupkg` 和 `releases.<channel>.json` 放在绝对路径的 feed 目录。单独的业务数据库和 SDK 缓存缺一不可。以终端启动测试 app：

```bash
GULU_DIAGNOSTICS=1 \
GULU_DATA_DIR=/absolute/ota-test/data \
GULU_UPDATE_DIR=/absolute/ota-test/feed \
'/absolute/ota-test/GuluTwist Break Station.app/Contents/MacOS/gulu-twist'
```

Windows 在 PowerShell 中分别设置三个同名环境变量，再启动测试安装的 `current/gulu-twist.exe`。必须使用隔离 Windows 用户或 VM，避免同 package ID 的用户级安装覆盖日常安装。诊断数据目录必须是绝对路径；同时提供前两个变量才允许文件源和独立 `data/velopack-packages` 缓存。普通客户端固定生产 GitHub 源。诊断入口不绕过摘要、身份、渠道、版本或保存检查。

为验证离线缓存，下载完成后移走 feed 中的清单和包（保留 feed 目录）。不能改动已保存的原始摘要，也不能通过替换缓存来假装下载成功。更新器启动日志默认仍位于 Velopack 的系统日志目录，应用与缓存/数据库保持隔离。

## 验收表

| 用例 | 操作 | 应看到的结果 |
| --- | --- | --- |
| 首次迁移 | 复制旧版测试数据，用 A 打开 | 设置、记录、浮窗偏好保留；业务数据目录不变 |
| 自动下载 | A 完成首次引导，等待 30–90 秒；B feed 可用 | 后台下载，不阻塞提醒；独立提示出现 |
| 手动入口 | 关闭自动检查，点击关于页“检查更新” | 仍可检查并下载；开关重启后保留 |
| 稍后 | 点击稍后；隐藏/重新打开主窗 | 同一进程不再弹，关于页保留重启入口 |
| 冷启动 | 有缓存时普通退出再运行 A | 仍为 A；再次提示，绝不静默安装 |
| 弹窗关闭 | 分别 Esc、标题栏关闭、Mac Cmd-W | 等同稍后，主业务继续 |
| 受保护状态 | 在体验休息/正式休息/锁屏期间完成下载或已弹提示后进入休息 | 提示收起，解除保护后再出现；不能强行结束休息进行更新 |
| 隐藏草稿 | 保留更新弹窗，用应用菜单打开主窗；修改设置；关闭主窗后在弹窗点重启 | 重新打开设置，明确提供保存/放弃/继续编辑 |
| 保存草稿 | 选择保存并离开 | 有效设置保存后自动继续本次更新，新版仍保留设置 |
| 取消草稿 | 选择继续编辑；以后正常保存 | 不更新；不能保留隐藏的重启意图 |
| 放弃草稿 | 选择放弃修改 | 旧设置保留，继续已确认的更新 |
| 无效草稿 | 输入不合法值，选择保存 | 明确错误、不安装；修正后普通保存不能意外更新 |
| 离线安装 | 下载 B 后移走 feed 清单，普通退出再启动 A，主动重启 | 复核缓存后应用 B；再次打开版本正确，原数据保留 |
| 同名坏缓存 | 修改缓存包内容或大小，主动安装 | 不启动替换器；清除就绪描述，允许重新检查下载 |
| 空/错源 | 移走清单，放入错误 channel、prerelease 或错误摘要 | 明确失败，不能假报最新 |
| 保存失败 | 在**测试库**加入拒绝写入的 SQLite trigger，再点重启 | 旧版保持运行，无 UpdateMac/Update.exe 等待退出；删除 trigger 后可重试 |
| 保存竞态 | 检查自动化取消/事务回滚测试；在测试机注入存储延迟 | 10 秒取消安装授权，迟到提交只对齐已保存状态，不重新启动更新器 |
| 辅助器失败 | 测试安装中移走/限制 UpdateMac 或 Update.exe，再主动安装 | 仍用旧版，显示错误；没有遗留等待进程 |
| 空间/权限 | 在 VM 制造缓存空间不足、安装目录不可写、Windows 文件占用 | 明确失败，业务数据保留；修复环境后重试 |
| 升级后 | 验证托盘、悬浮窗、通知点击、休息、单实例 | 与升级前一致；已应用的就绪标记清理 |
| GitHub 草稿 | 维护者下载三目标草稿包用上述文件源验收；正常匿名客户端检查 | 草稿不可发现 |
| GitHub 公开 | 维护者手动公开后用 A 检查 | 从真实 HTTPS 附件下载并升级到 B；记录重定向/限流表现 |
| 发布保护 | 运行脚本测试，再用测试仓库验证中断重试 | 相同原始 artifact 可恢复；公开版、不同 SHA/摘要均拒绝覆盖 |
| 卸载重装 | 原生 Windows 卸载后重装；Mac 手动换包 | 用户数据保留；旧 Inno/便携入口由用户停用，避免启动旧副本 |

保存失败注入仅限本次创建的测试数据库：

```sql
CREATE TRIGGER ota_fail BEFORE INSERT ON preferences
BEGIN SELECT RAISE(ABORT, 'OTA test: write failed'); END;
-- 完成失败验证后恢复测试库：
DROP TRIGGER ota_fail;
```
