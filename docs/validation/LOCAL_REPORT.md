## 已修复的本机问题

1. GPUI 初始化函数重名，改为明确调用 Kit 初始化。
2. 锁屏取消待办后错误扣减新间隔，调整为先累计旧状态再取消。
3. 强制遮罩降级后稍后提醒可能再次强制，改为实例保留 gentle 标识。
4. 相同稍后回调可能重置倒计时，限制仅处理当前待办实例。
5. 重复卡片的辅助文案使用相同可访问 ID，调试版因此报重复节点；给卡片/表单/记录建立独立标识后复测通过。
6. 页面切换保留上一页滚动位置，改为页面独立滚动状态；保存后进入首页。
7. 小屏遮罩内容可能挤占退出入口，最终版将内容设为可滚动、退出区固定，并适配低高度屏幕。解锁后的 Release 回归已看到固定退出按钮，并验证按钮退出、Esc 退出与五秒自然结束；极端小屏仍待测。
8. 补齐 macOS `⌘W` 和“关闭窗口”菜单；主窗口复用隐藏逻辑，休息中复用紧急退出逻辑。首页剩余间隔和状态提示增加可访问标签。代码检查通过；第二次解锁回归已验证快捷键，托盘图标点击仍待人工验证。
