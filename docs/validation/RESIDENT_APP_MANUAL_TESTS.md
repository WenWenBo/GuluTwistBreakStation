# 菜单栏／托盘常驻手工回归

日期：2026-10-14。目标版本 0.1.0，Mac build 6。当前实测范围与包校验和见 [本轮报告](RESIDENT_APP_REPORT.md)。本文是待执行步骤，不代表已通过；完整编号定义见 [实现计划第 10 节](../implementation/RESIDENT_APP_PLAN.md)。

## 1. 使用独立数据启动

测试前从旧测试实例的菜单选择退出。相同 `GULU_DATA_DIR` 会激活旧实例，不能用新环境变量改变旧进程行为。不要把测试包覆盖到日常安装位置，也不要复用日常数据库。更换测试场景时先正常退出，关闭窗口只是隐藏。

Mac（仓库根目录；Intel 改为 `x86_64-apple-darwin`）：

```bash
mkdir -p dist/resident-manual
GULU_DATA_DIR="$PWD/dist/resident-manual" GULU_DIAGNOSTICS=1 \
  'dist/aarch64-apple-darwin/GuluTwist Break Station.app/Contents/MacOS/gulu-twist' \
  2>dist/resident-manual.log
```

该命令前台运行，从菜单退出后返回终端。已引导后的冷启动正常只显示菜单栏，胶囊是否显示按开关决定。

单实例重开：另开终端，在相同仓库目录执行同一命令和相同数据目录，但不再重定向已有日志。第二个进程应很快退出并请求原窗口恢复。正式 Finder／Spotlight 启动另在干净测试用户下测试，确保默认数据目录也属于测试用户；其证据不能由终端直接运行代替。

Windows（原生 PowerShell，仓库根目录）：

```powershell
./scripts/package-windows.ps1 -SkipInstaller
$env:GULU_DATA_DIR = Join-Path $PWD 'dist/resident-manual'
$env:GULU_DIAGNOSTICS = '1'
& ./target/x86_64-pc-windows-msvc/release/gulu-twist.exe
```

或对解压后的便携版执行相同环境配置，再启动 `gulu-twist.exe`。GUI 程序可能立即返回终端，先确认托盘进程退出再开始下一场景。第二次启动应使用完全相同的环境变量；Windows 安装版另用 `./scripts/package-windows.ps1` 生成，要求 Inno Setup 6，在普通用户测试会话验证开始菜单启动和卸载。

## 2. 共同行为

| 场景 | 操作 | 必须观察到的结果 |
| --- | --- | --- |
| C-01 首次引导 | 使用新的隔离目录启动；先体验 5 秒，再确认引导 | 引导前不正式计时，体验不记账；保存成功后窗口收起；失败时保留窗口 |
| C-02 安静启动 | 完成引导，分别开启／关闭胶囊并正常退出重启 | 两种状态都不弹主窗；胶囊开关保留；菜单入口可用 |
| C-03 静态状态 | 分别保存所有事项关闭、手动暂停、当前不在工作时段，退出重启 | 不主动弹主窗，菜单状态正确，无错误提醒 |
| C-04 隐藏重开 | 打开主窗口后关一次，再从图标打开 | 一次关闭即隐藏；只有一个主窗；计时继续 |
| C-05 草稿保护 | 修改某项但不保存，隐藏后重开；点击“提醒设置”；再经胶囊进入首页或点击正式包测试通知 | 草稿仍在；离开设置触发原来的未保存选择，不能默默保存或丢弃 |
| C-06 最小化 | 最小化主窗，再从图标打开；重复启动原实例 | 主窗还原并可操作，页签和草稿仍在，没有新增窗口 |
| C-07 无窗提醒 | 测试配置设为当日全天、五分钟间隔，至少一项轻提醒、一项全屏；关闭胶囊与主窗并等待 | 两种提醒按规则出现；全屏结束／点击紧急退出只记一次；无主窗也正常调度 |
| C-08 休息退出 | 各屏体验及正式休息时按 Esc、返回、⌘W／Alt+F4，再点击文字 | 按键不结束休息；文字灰色、下划线、hover 手形，点击撤下全部遮罩；体验不记账 |
| C-09 延后打开 | 休息期间重复启动，或从可达图标请求设置；锁屏期间由第二终端请求同一实例；之后结束／解锁 | 不绕过休息／锁屏，恢复后只开一个主窗；最近明确目的地保留；再次普通重开不覆盖设置目的地 |
| C-10 单实例 | 连续启动同一数据目录 3 次，退出后再启动 | 只有一个托盘和计时器；正常退出释放锁；再次冷启动安静 |
| C-11 故障入口 | 执行下节每项注入和恢复 | 对应提示／兜底／退出可操作，不留下没有入口的后台进程 |
| C-12 完整退出 | 分别在纯托盘、正在休息、正在保存时从菜单退出；Mac 另测系统退出 | 图标、辅助窗口和进程消失，设置／记录正常落盘；系统退出和菜单退出不重复结算 |
| C-13 系统事件 | 锁屏、真实睡眠跨过休息截止点、跨工作边界、拔插显示器 | 间隔冻结／恢复缓冲正确，过期休息不重弹，原截止点不延长，无残留遮罩 |
| C-14 重复生命周期 | 隐藏／重开至少 20 次，正式休息至少 20 次 | 无重复图标／回调／记录，无残留工具窗；记录性能样本以判断增长 |

普通系统前台限制可能拒绝应用抢焦点；不得通过循环强抢焦点获得“通过”。通知请从正式包测试，开发二进制不能替代通知身份验收。重开不等于保存，首次引导保存收起与普通设置保存需分别检查。

## 3. Mac 专项（Apple Silicon 与 Intel 分别记录）

- **M-01**：Finder 和 Spotlight 冷启动及重复启动，录屏或现场观察启动全过程无运行态 Dock 闪现；⌘Tab 不列出本应用。手动固定的静态 Dock 图标不要求移除。
- **M-02**：打开设置，输入中文／数字、Tab 切换控件、保存／取消、关闭重开、最小化还原；应用保持菜单栏模式，窗口可编辑。
- **M-03**：至少双屏、普通 Space、另一个应用全屏状态下体验及正式休息。检查全屏覆盖、焦点和退出恢复；每块屏幕均可点击退出。
- **M-04**：用 `tray-once` 验证首次失败临时有 Dock，点击重试后图标恢复、Dock 消失；当前兜底窗口仍保留并可编辑，关闭一次即可隐藏。重试多次不增加图标或回调。
- **M-05**：开发命令启动同样无 Dock；正式包发送测试通知并点击，正在编辑时走导航保护。不同架构必须分别实测，Rosetta 或交叉构建不能代替 Intel 真机。

## 4. Windows 专项（Windows 10 与 11 分别记录）

- **W-01**：主窗显示和最小化时存在任务栏／Alt+Tab 项；关闭后消失；托盘重开正确还原。观察的应是运行窗口项，用户固定的静态快捷入口不算残留。
- **W-02**：分别显示胶囊、更多菜单、多条轻提醒和多屏遮罩，关注创建瞬间及整个显示期间均无辅助任务栏／Alt+Tab 项。
- **W-03**：托盘左键开窗、右键菜单；用系统键盘操作通知区域；将图标移至 ∧ 区再展开，所有菜单可达且不出现“图标不可用”误报。
- **W-04**：在专用测试会话，用任务管理器重启 Windows 资源管理器。正常由托盘库自动恢复为唯一图标；若注册未恢复，最多约 30 秒后保留兜底主窗并可重试。另测试 Explorer 尚未就绪时启动。应用提醒计时不重置；锁屏时故障窗口延后显示。不要在有未完成文件操作的日常会话执行。
- **W-05**：100%／150%／200% DPI、混合缩放跨屏、主屏切换和拔屏，检查恢复位置、菜单可点、无屏外残留和意外任务栏图标。
- **W-06**：安装版／便携版各在普通权限运行；检查启动、通知点击、单实例、设置保留、退出和卸载。无管理员权限要求，不注册新服务或开机启动项。

## 5. 故障注入与恢复

仅在设置 `GULU_DIAGNOSTICS=1` 时读取 `GULU_TEST_FAILURES`，逗号分隔：

| 值 | 注入 | 预期 |
| --- | --- | --- |
| `tray` | 每次图标创建失败 | 主窗保留，Mac 临时普通应用；关窗不能丢失最后入口；重试仍失败但可退出 |
| `tray-once` | 本进程仅首次图标创建失败 | 首次兜底；点“重试常驻图标”恢复唯一图标、清错误；再次关窗正常隐藏 |
| `tray-registration` | 对象存在但可用性确认失败 | 同样保持主窗；验证不能用对象存在代替注册成功；持续注入时重试不能假报成功 |
| `main-window` | 主窗创建／显示失败 | 点击托盘打开时有原生提示，图标仍可暂停／退出，下一次明确打开仍可重试 |
| `tray,main-window` | 两种入口均失败 | 原生提示确认后清理退出；进程和实例锁不残留 |

Mac 示例（退出前一个测试实例，再运行）：

```bash
GULU_DATA_DIR="$PWD/dist/resident-fault" GULU_DIAGNOSTICS=1 \
GULU_TEST_FAILURES=tray-once \
  'dist/aarch64-apple-darwin/GuluTwist Break Station.app/Contents/MacOS/gulu-twist' \
  2>dist/resident-fault.log
```

Windows 示例：

```powershell
$env:GULU_DATA_DIR = Join-Path $PWD 'dist/resident-fault'
$env:GULU_DIAGNOSTICS = '1'
$env:GULU_TEST_FAILURES = 'tray-once'
& ./target/x86_64-pc-windows-msvc/release/gulu-twist.exe
```

组合失败的原生对话框需先确认后才退出。持续故障变量不能在正在运行的进程外解除；退出后移除变量再启动验证恢复，`tray-once` 则专门用于同进程重试成功。macOS 的 `tray-registration` 是策略注入，并非模拟真实 NSStatusItem 注册 API；Windows 的真实注册与 Explorer 恢复仍须 W-04 实测。

故障测试结束后在 PowerShell 执行：

```powershell
Remove-Item Env:GULU_TEST_FAILURES -ErrorAction SilentlyContinue
Remove-Item Env:GULU_DIAGNOSTICS -ErrorAction SilentlyContinue
Remove-Item Env:GULU_DATA_DIR -ErrorAction SilentlyContinue
```

Mac 命令前缀环境只对本次进程生效。保留测试目录和日志作为证据；日后清理只删除明确的隔离目录，不能删除日常数据库。进程无响应时先记录 PID，再只终止对应测试进程，不使用批量结束同名进程命令。

## 6. 性能与长稳

在同机、同隔离配置、同 Release 编译参数下，对比基线 `758483f` 与新版本，分别测纯托盘、托盘＋胶囊、主窗可见。各预热 5 分钟、采样 30 分钟，记录 CPU、RSS（Mac）／工作集（Win）、可见窗口数与计时状态；不能只比较有无 Dock。

目标沿用 PRD：平均 CPU ≤ 单逻辑核 0.5%，空闲内存 P95 ≤ 200 MiB；连续 8 小时含至少 20 次遮罩、10 次锁屏恢复，空闲内存增长 ≤ 30 MiB，无崩溃／残留；到期延迟 P95 ≤ 2 秒，点击紧急退出至全部撤罩 ≤ 1 秒。冷启动至图标可操作 ≤ 3 秒，常规反馈 ≤ 200 ms。性能未采样不能写“显著降占用”。
