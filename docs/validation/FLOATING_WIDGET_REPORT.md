# 紧凑胶囊 · 实现与验证报告

日期：2026-10-13。版本：0.1.0 / macOS build 4。功能分支：`feat/compact-floating-capsule`，从 `origin/main` 的 `fa790ab` 创建。

**状态：功能代码、自动检查与 Mac 双架构构建完成；本轮桌面交互尚未验收。** 本机界面工具持续报告 Mac 锁屏，已请求用户解锁，未取得本轮实际窗口、拖动或焦点的验证证据。Windows 原生编译、Windows 10 和 Intel Mac 实机运行也尚未完成。不能把以下构建结果解释为所有平台已通过。

## 1. 已实现范围

- 200 × 52、半径 26 的胶囊：内嵌小咕图标、最近事项、等宽倒计时、更多菜单；随系统切换局部明暗配色。
- 主窗口与胶囊可以共存。点击图标／时间打开主窗口，关闭主窗口保留胶囊；设置、托盘和更多菜单可显示／隐藏。隐藏不暂停、不重置提醒。
- 结构化只读引擎摘要按实际毫秒选最近事项，区分稍后、到期未通知、已通知待处理、暂停、非工作时段、全部禁用与异常。
- 独立保存 UI 偏好，旧用户默认关闭；开关即时保存，位置防抖写入。回执带版本，失败恢复已保存的开关，位置失败保留本次坐标；退出前把最新位置加入存储队列。
- 原生拖动、位置恢复、工作区限制、显示器断开回退、重置；独立菜单窗口，避免在 52 高度内被裁切。
- 正式休息、体验、锁屏和退出期间隐藏；被动显示不调用激活，普通桌面置顶。正常冷启动允许仅显示胶囊与托盘，异常保留主窗口入口。
- Mac 和 Windows 独立适配；Windows 使用工具窗口样式、非激活显示、原生圆角区域和目标屏幕工作区／缩放，不依赖 Windows 11 圆角。

关闭命令按主窗口／胶囊／菜单／遮罩分别路由。外观保存不调用提醒规则保存，也不清除主窗口未保存草稿。

## 3. 源码核查与修正

- GPUI Kit 的通用根视图会铺主题背景。胶囊和菜单直接作为透明窗口根视图创建，显式继承字体，避免额外方形底板。
- GPUI macOS 的窗口与可用工作区坐标相对所属屏幕；原生定位按目标 `NSScreen` 转换，不把副屏坐标当成全局坐标。重置时同时比较屏幕和坐标，避免同尺寸屏幕之间不移动。
- 鼠标点击与原生拖动分开；补上键盘／辅助功能点击入口。操作标签不含每秒变化的时间，避免焦点标签持续变化；实际 VoiceOver 仍未验证。
- 保存最终位置时考虑先前写入尚未回执，按 FIFO 在退出屏障前提交最新状态。失败不建立无限重试循环。
- 冷启动遇到 UI 或存储错误会打开主窗口；创建失败保留入口且不每秒重复创建。

以上属于源码与自动检查结论，不是 GUI 操作结果。
