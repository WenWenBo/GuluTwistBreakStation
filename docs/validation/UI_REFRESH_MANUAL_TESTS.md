# 视觉更新：Windows 10 / Intel Mac 手动验证

使用 0.1.0 的小咕视觉更新包（Mac 构建号 3），先记录 ZIP 的 SHA256、系统版本、显卡、每屏分辨率和缩放。Intel 需 macOS 15+；Windows 需 Windows 10 22H2 x64。安装、隔离测试数据及 Windows 构建操作沿用 [完整手册](MANUAL_TEST_GUIDE.md)。旧包仍是圆脸图标时，不要把旧版本结果填入本表。

build 3 专项：先退出旧实例，在相同位置替换应用，再启动；检查运行中的 Dock 已显示小咕。保留旧固定入口时再检查退出后的图标。不要通过重置整个 Dock 或系统图标缓存代替应用升级验证。

| 编号 | 操作 | 通过标准 |

| V-01 | Finder / Dock，或资源管理器 / 开始菜单 / 任务栏观察图标 | 伸展的小水团，透明外角，无方形底色；16/32/64 等尺寸边缘干净 |
| V-02 | 打开和关闭主窗口，从菜单栏 / 托盘操作 | Mac 单色小咕清晰；Win 小图非默认 EXE；图标点击能打开已有菜单 |
| V-03 | 系统浅色 / 深色菜单栏分别观察 | 模板可辨认，不出现白色方块；应用本轮仍固定浅色界面 |
| V-04 | 默认窗口，再逐步缩到 640×480 | 默认完整看到四卡；窄窗口为图标导航 + 单列，工具提示和保存按钮可达 |
| V-05 | Windows 100/125/150/200%；Mac默认及另一缩放，跨屏拖动主窗口 | 无裁字、覆盖、横向溢出；所有输入和按钮可见，可滚动到末尾 |
| V-06 | 设置休息 1 分 30 秒保存重开；再分别把秒改 60、总计改 0/1801 秒 | 正确值重开保持；非法值就地报错、不保存、输入保留 |

| V-10 | 工作时段覆盖当前、四项间隔 5 分钟，休息设 1 分 5 秒 | 自然合并一场；观察 01:05、01:00、00:59、00:11、00:10、00:04、00:01，数字与冒号完整、不抖动 |

| V-13 | 清空记录先点保留；再次确认清空测试记录 | 第一次保留；确认后空状态清晰，设置不变；勿用正式数据 |
| V-14 | 设置只读目录 / 损坏测试数据库（先备份） | 持久化失败保留输入；恢复页没有假正常状态，操作与文字可读 |
| V-15 | Tab / Shift+Tab / Enter；VoiceOver 或 Narrator | 图标按钮有名字，字段含事项与分秒单位，焦点可见，倒计时不每秒打断读屏 |

V-06 表中错误测试应分别进行；秒数必须 0–59，总范围 5–1800 秒。休息到零后立即撤罩，正常产品不刻意停留在 00:00。

## 三屏与睡眠回归

本轮修正了 Mac 原生遮罩样式，必须重新检查：每屏顶边和底边均覆盖，按钮离边缘有余量；各屏退出、全屏应用 / Space、插拔显示器均无卡住窗口。锁屏期间间隔暂停，正式休息截止点继续前进；真正睡眠需日志中连续时钟差明显大于清醒时钟差，不能以锁屏代替。

完整步骤沿用完整手册第 4–7 节。异常时先用 Esc / 托盘紧急退出；仍失败则系统强制退出并记录最短复现路径。
