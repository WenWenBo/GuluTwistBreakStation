# 清单、输入与全屏退出设置｜手工验证

基线：[专项 PRD](../../tasks/prd-floating-list-time-input.md)。实际结果：[交付报告](FLOATING_LIST_TIME_INPUT_REPORT.md)。以下是操作步骤，未勾选项不代表通过。

## 准备

使用独立数据目录启动对应平台的最终包，记录 OS、架构、主题、缩放和显示器数量。不要使用日常数据。Mac 示例：

```sh
GULU_DATA_DIR="$PWD/dist/floating-list-test" GULU_DIAGNOSTICS=1 \
  'dist/aarch64-apple-darwin/GuluTwist Break Station.app/Contents/MacOS/gulu-twist'
```

保存五项启用、不同间隔、全天工作；若使用本次隔离目录，喝水 5、颈肩 10、如厕 240、站立 15、护眼 5 分钟，护眼全屏 60 秒（输入验收后保存）。另一个 `dist/floating-list-boundaries` 目录全部为轻提醒，除如厕 240 分钟外均为 5 分钟。设置页部分控件在滚动区域外，必须滚动到可见位置后再点击，并核对保存结果；可访问树中存在控件不等于点击已成功。

## 清单（AT-01～09）

1. 关闭主窗，点击 `···` 前清单图标。核对所有启用事项、秒级刷新、三位分钟及倒序；主胶囊仍为最近事项。同值按喝水、颈肩、如厕、站立、护眼排序。
2. 点击一项 `✓`，记录点击前后倒计时和今日记录；该行反馈约 1 秒、保持展开、随后显示完整新间隔并重排，其他项不重置。快速双击和按下期间跨一次刷新，不应误完成别项或新一轮。
3. 主窗和清单对同一旧轮次先后完成，记录只能增加一次。若使用辅助操作工具发送延迟动作，应确认动作携带旧轮次，而不是重新查询后的新按钮。
4. 等待至少一项轻提醒到期，将另一项稍后 5 分钟；清单待完成项在底部，稍后项显示其余量。开合清单仅恢复仍未完成的独立提醒条。
5. 验证再次点击、Esc、外部点击收起；点击行内空白保持展开；清单与更多互斥。Tab 能到达各行完成，Enter／Space 只作用当前项。
6. 拖动胶囊、跨屏、底边展开、小工作区滚动；列表跟随且按钮可见，向上展开仍为从长到短。深浅主题与不同缩放分别记录。
7. 暂停、下班、全部关闭、隐藏、锁屏、正式休息和体验分别检查入口禁用／整组收起，恢复后不自动展开；清单不能结束已开始的全屏。

## 时间与数字（AT-10～16）

1. 通过小时／分钟分段将 `09:00` 改为 `09:30`；验证方向键、Tab、数字连续输入，中文／冒号不产生非法时间。新增和首次引导使用同样控件。
2. 配置 `12:00–09:00`、重叠时段并保存，必须阻止；修正后保存。相邻时段合并，1–4 段及无工作日沿用原规则。
3. 加载 `00:00–24:00`，仅聚焦不产生脏状态；取消“至当天结束”显示 `23:59`。修改为 `18:30`，勾选再取消恢复 `18:30`；重新勾选保存并重启仍为 1440。
4. 五项的间隔／休息分钟／休息秒逐类测试：键入中文、字母、负号、小数点；选中后粘贴 `1.5`、`-5`、`20分钟`、`1\n5`、全角数字及空格，全部整次拒绝、原值保持、提示可见。
5. 清空后重填、剪切、合法数字粘贴、前导零失焦、撤销重做。间隔 5／240 可保存，4／241／空值不可；休息 0:05／30:00 可保存，0:04／0:60／30:01／超长数字不可。不自动截断、进位或钳制。
6. 无效草稿不影响当前计时，取消恢复原值；合法草稿保存重启正确。切换轻提醒／全屏和停用时保留原时长。

## 全屏退出（AT-17～21）

1. 默认未勾选“禁用退出全屏按钮”，体验及正式遮罩只显示“退出”；允许状态点击任意屏幕即撤下全部遮罩。正式只记一次 Interrupted，体验不记录。
2. 勾选但不保存，启动体验仍按上次保存值；取消后没有运行配置变化。
3. 勾选并保存、重启核对，体验按钮灰色不可用；点按、Tab／Enter／Space 和辅助技术操作均不能退出，5 秒后自动关闭且无记录。
4. 正式全屏重复上一步，所有显示器一致；自然结束仅按正式事项记录 Timed。显示器重建保持本场权限。
5. 取消勾选并保存，下一场恢复可退出；仅保存此项不重置提醒或清空待办。一场内配置变化不改变本场权限；旧场次回调不能结束新场次。
6. 验证全局暂停、退出应用、工作时段边界仍清理遮罩，真正的窗口失败仍降级，不把正常禁用状态判为故障。原配置缺字段、备份、保存失败和旧会话恢复可先核对自动测试。

## 2026-10-15 补测提示
