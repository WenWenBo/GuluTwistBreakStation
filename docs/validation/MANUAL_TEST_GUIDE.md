# Windows 10 / Intel Mac 手动验证步骤

版本：0.1.0（小咕视觉更新，Mac 构建号 3）；请同时执行 [视觉专项](UI_REFRESH_MANUAL_TESTS.md)。此文档是操作清单，不是通过报告。先使用个人测试数据；完成后把末尾记录表交回即可定位问题。基础流程约 30–45 分钟，长时间稳定性另做 8 小时。

## 1. 准备设备和包

| 机器 | 系统基线 | 应用 |
| --- | --- | --- |
| Intel Mac | macOS 15，Intel x86_64 | `GuluTwist-0.1.0-build3-x86_64-apple-darwin.zip` |
| Windows | Windows 10 22H2 x64，实际 GPU/驱动需记录 | Windows 原生构建的安装 EXE / portable ZIP |

Intel 包已可从本项目交叉构建；不能把 M4 上 Rosetta 运行当作 Intel 实测。Windows 包需要在 Windows 构建，当前 Mac 缺 Windows SDK / 资源编译器，未交付声称已验证的 Windows EXE。

Windows 首次构建：

1. 安装 [Rust](https://rustup.rs/)、[Visual Studio 2022 Build Tools](https://visualstudio.microsoft.com/downloads/)，选择“使用 C++ 的桌面开发”及 Windows 10/11 SDK。构建机可以是 Windows 11；运行验收仍须 Windows 10。
2. 如需安装 EXE，安装 [Inno Setup 6](https://jrsoftware.org/isinfo.php)。
3. 将完整项目拷贝到本机。打开“Developer PowerShell for VS 2022”，进入项目目录。
4. 运行以下命令，出现错误时保留完整输出，不继续把构建视为成功：

```powershell
cargo test --locked --workspace
./scripts/package-windows.ps1
```

不安装 Inno Setup 时执行 `./scripts/package-windows.ps1 -SkipInstaller`，得到便携 ZIP。产物在 `dist`。正式运行不需要 Rust 或开发工具。Windows 显卡驱动需要支持 GPUI 使用的 DirectX 后端；黑屏/启动失败时记录 GPU 型号、驱动版本与截图。

Mac 安装：解压、拖到“应用程序”。Windows 安装：运行 Setup、保持默认当前用户路径；确认开始菜单入口。系统信任提示由你核对来源并决定，不建议全局关闭系统安全设置。

## 2. 记录环境与数据隔离

Mac“关于本机”记录系统、芯片、内存；Windows `winver` 记录版本/构建号，“设备管理器 → 显示适配器”记录 GPU。记录每个屏幕分辨率、缩放、排列以及镜像/扩展模式。

建议验证时使用独立数据目录。Mac 终端：

```bash
mkdir -p "$HOME/GuluTwistTest"
GULU_DATA_DIR="$HOME/GuluTwistTest" GULU_DIAGNOSTICS=1 \
  '/Applications/GuluTwist Break Station.app/Contents/MacOS/gulu-twist' \
  2> "$HOME/GuluTwistTest/runtime.log"
```

Windows PowerShell（安装版默认位置）：

```powershell
$env:GULU_DATA_DIR = Join-Path $env:USERPROFILE 'GuluTwistTest'
$env:GULU_DIAGNOSTICS = '1'
New-Item -ItemType Directory -Force $env:GULU_DATA_DIR | Out-Null
& "$env:LOCALAPPDATA\Programs\GuluTwist\gulu-twist.exe"
```

若另有常驻实例，先从托盘退出。测试进程结束后关闭测试终端；正常双击运行不继承该临时环境。日志和数据库只在你需要排查时自行提供，不自动上传。

## 3. 安装、引导与保存（约 5 分钟）

| 编号 | 操作 | 期望 |
| --- | --- | --- |
| M-01 | 断网打开，暂不确认引导，等待一分钟 | 界面正常，无登录、无自动遮罩 |
| M-02 | 检查四类默认值；点五秒体验，按 Esc；再次体验，点紧急退出 | 任一路径全部遮罩在一秒内消失，应用仍在，无正式记录 |
| M-03 | 间隔填 4、时长填 0、时段填 25:00、创建重叠时段分别保存 | 明确错误，不保存，输入保留 |
| M-04 | 选择今天，时段设为当前时间覆盖范围，四项间隔都设 5 分钟，时长设 5/10/15/10 秒，强制模式并保存 | 回首页；四项从五分钟倒计时 |
| M-05 | 退出再启动，检查设置和记录 | 设置保留、间隔从完整五分钟开始，无补发旧提醒 |

## 4. 强制提醒、多屏和退出（约 10 分钟）

1. 连接至少两台显示器，使用扩展模式；分别把文档或浏览器放在各屏。
2. 保持五分钟测试配置，等待自然到期。记录到期和遮罩出现的时间。
3. 检查每个屏幕都有遮罩，无普通应用可以通过遮罩点击。每屏标题包含四项，共享约 15 秒倒计时；不是 40 秒。
4. 自然结束后，首页应为休息 1 场、计时完成事项 4 次；记录各一条，无重复。
5. 再次五秒体验，在不同屏幕分别点击退出；在获得焦点的遮罩按 Esc。每次应同时撤下全部屏幕遮罩。
6. Windows 测 100% + 150%/200% 混合缩放；Mac 测 Retina + 外接屏。遮罩、提示和按钮完整。
7. 在体验开始前打开一个全屏应用；Mac 在不同 Space 切换，Windows 在虚拟桌面切换。记录具体哪些桌面/全屏场景可覆盖，不把安全桌面作为覆盖对象。
8. 为热插拔测试，把一个事项休息时长设 180 秒，重新保存并等待自然到期。休息中插拔外接屏、改变分辨率和主屏，截止时间不得重新开始，任一仍活动屏可退出。
9. 测完确保没有透明窗口残留；点击原先的应用，正常操作。

出现遮罩无法退出时：先 Esc，再用托盘“紧急退出本次休息”；仍不行，用操作系统强制结束应用并记录环境。不要把绕过系统安全能力作为缺陷或需求。

## 5. 锁屏、睡眠与工作边界（约 15–20 分钟）

准备手机秒表。真实睡眠与单纯锁屏必须分开测试。

| 编号 | 步骤 | 期望 |
| --- | --- | --- |
| M-10 间隔锁屏 | 五分钟间隔运行两分钟，锁屏一分钟，解锁 | 剩余约三分钟，锁屏一分钟没有消耗间隔；误差记录到秒 |
| M-11 临近到期恢复 | 剩余约 20 秒时锁屏一分钟再解锁 | 至少 60 秒有效时间后才有新提醒 |
| M-12 休息锁屏 | 休息时长设 120 秒；自然到期后 30 秒锁屏，等两分钟后解锁 | 旧休息已完成，遮罩不重弹，只产生一份完成记录 |
| M-13 休息睡眠 | 同样的 120 秒休息，开始后 30 秒使电脑真实睡眠，等两分钟唤醒 | 同 M-12，完成时间按实际截止，不写成唤醒时间 |
| M-14 未到期唤醒 | 180 秒休息开始后，睡眠约 30 秒并唤醒 | 继续剩余时长，不从 180 秒重来 |
| M-15 工作边界取消 | 设一个六分钟工作时段、五分钟间隔、三分钟休息；休息开始后等待时段结束 | 时段结束撤罩，记取消，不记完成；下一时段重新计时 |
| M-16 睡眠跨边界 | 分别配置“休息先结束”和“工作时段先结束”，睡眠到两个时间都过去再唤醒 | 前者完成、后者取消；不要出现旧遮罩 |
| M-17 改时钟 | 休息中把时间前/后调整但仍在同一工作时段；另一次改到时段外 | 同时段内不改变休息秒数，跨出则取消；测试后恢复系统自动时间 |

M-17 会改变整台机器时间，建议在测试机执行。无需在工作电脑上关闭自动时间来完成其它用例。

## 6. 轻提醒、暂停、数据（约 10 分钟）

1. 切换轻提醒，保存五分钟间隔。在设置中发送测试通知，按系统提示决定通知授权。记录允许、拒绝、专注模式下是否显示；没有通知也应能在首页处理。
2. 到期后立即处理：喝水“已完成”，颈肩“稍后 5 分钟”，如厕“跳过”，站立保持不处理两分钟。应依次为手动完成、暂未终结、已跳过、未处理；没有遮罩。
3. 稍后五分钟只累计有效工作时间，期间不会生成该项常规提醒；再到期仍是轻提醒。点击旧通知只打开小站，不重复计数。
4. 分别暂停 15 分钟、手动暂停并恢复，检查剩余时间冻结；“下一工作日”不可指向当天午休后。
5. 主动完成双击，不应连续记两条。关闭主窗口后从托盘重开；重复启动应用，任务管理器/活动监视器只有一个调度进程。
6. 从托盘退出，确认无进程、无遗留遮罩。再启动不补发。
7. 在独立测试目录中测试清空记录：先取消确认，记录还在；再确认，全部清空，设置不变。
8. 验证损坏恢复：先退出，备份测试目录，将测试数据库替换为纯文本文件，再启动。应提示恢复、无自动提醒，确认使用默认后旧文件仍以 recovery 名称保留。不要操作正式目录。
9. 覆盖安装同版本，再启动，确认设置和记录保留。卸载后无进程，数据默认保留，用户可单独删除。

Mac 另测 `⌘W`：主窗口首次关闭出现常驻说明，再次关闭隐藏窗口；从菜单栏重开后可继续操作。遮罩上按 `⌘W` 应结束本次休息，和 Esc 一样撤下所有遮罩。

启用 `GULU_DIAGNOSTICS=1` 后，日志里的 `clock_transition` 记录锁屏状态变化、清醒时钟差值和连续时钟差值，`clock_reconciled` 记录核算后的间隔与休息截止点。真实睡眠时连续时钟差值应明显大于清醒时钟差值；单纯锁屏不能替代此项证据。

## 7. 性能和可访问性

Release 包隐藏窗口、无活动遮罩，预热五分钟后采样 30 分钟。记录进程 CPU、RSS/工作集 P95 与屏幕配置。CPU 以单个逻辑核 100% 为口径；目标平均 ≤0.5%，常驻内存 P95 ≤200 MiB。这些是验收目标，不是已经达到的数字。

八小时试用至少 20 次遮罩、10 次锁屏恢复，检查进程不崩溃、没有漏退出、没有内存持续增长。Mac VoiceOver / Windows Narrator 检查按钮名称、Tab 焦点和紧急退出可读，倒计时不每秒重复播报。窗口缩小到 640×480 后仍能滚动到保存和处理按钮。
