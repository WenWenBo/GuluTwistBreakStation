# 清单、输入与全屏退出设置｜实施报告

日期：2026-10-15。需求：[专项 PRD v1.1](../../tasks/prd-floating-list-time-input.md)。计划：[12 项开发任务](../implementation/FLOATING_LIST_TIME_INPUT_PLAN.md)。

> 后续修正（用户要求仅开发、不验证）：清单根背景改为透明，排序改为剩余时间越少越靠近主胶囊（下方升序、上方降序）；设置改名为“隐藏退出全屏按钮”，勾选后不渲染退出按钮及底部操作区域。此修正尚未测试、构建或打包，以下测试、截图、源码摘要及 build 8 ZIP 均属于修正前版本，不能作为本次修改的验证或交付包。

四项功能已实现，64 项自动测试、格式检查、严格 Clippy 和 Mac 双架构 Release 构建通过。用户解锁后已补验 TimeField、三类数字输入、正式／体验退出权限、清单双击去重和待办协调，并修复胶囊获得焦点时清单误收起的问题。完整跨平台及键盘／拖动边界仍有未测项，见下表。

## 1. 交付内容

- 胶囊为 236×52，`···` 前增加清单图标；独立弹层显示启用事项的真实剩余时间，毫秒倒序、同值固定顺序，支持稍后／待完成状态。
- 逐项完成绑定事项与当前轮次。只重置本项、产生一次手动记录，反馈约 1 秒后恢复新一轮倒计时；列表保持展开。旧轮次、旧清单实例和重复鼠标双击不会再次完成。
- 清单与更多菜单、轻提醒条协调显示；关闭恢复未完成待办，暂停／下班／锁屏／全屏等状态收起或禁用；弹层跟随胶囊、边缘翻转、小工作区滚动。
- 工作时段使用锁定依赖 GPUI Kit 0.7.3 的 TimeField，24 小时制、分钟精度。“至当天结束”保持 1440 的存储值和普通结束时间草稿。
- 三类时长字段共用 ASCII 数字校验，允许空编辑态；原始剪贴板与候选值均校验，避免组件移除换行后把 `1\n5` 变成 `15`。范围保持不变，失焦去掉前导零。
- 全屏按钮文案为“退出”。新增默认 false 的 `disable_fullscreen_exit`，保存后下一场正式／体验采用本场权限快照。命令先校验会话身份及权限，再关闭遮罩；自然结束、暂停和故障清理仍沿用原规则。
- 旧配置及旧会话缺字段按 false 读取，无数据库表结构或依赖升级。
