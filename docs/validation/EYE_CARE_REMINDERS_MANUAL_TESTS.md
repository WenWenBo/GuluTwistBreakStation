# 护眼与分项提醒：外机手动验证

适用版本：0.1.0 build 5。请分别在 Windows 10 x64、Intel Mac（macOS 15+）执行，记录系统版本、芯片／显卡、屏幕数量与缩放。Apple Silicon 的自动测试和本机结果见 [交付报告](EYE_CARE_REMINDERS_REPORT.md)，不能代替外机结果。

## 准备

1. 先退出旧版，备份整个数据目录。Mac 使用 build 5 的 x86_64 ZIP；Windows 按 [打包说明](../packaging.md) 在 Windows 构建。不要把 Apple Silicon 的 ZIP 给 Intel Mac。
2. 正常日常使用可直接升级；测试建议设置独立数据目录，避免影响自己的提醒及记录。
3. Mac 终端启动示例（替换实际应用位置）：
   ```sh
   GULU_DATA_DIR="$HOME/GuluTwist-eye-care-test" GULU_DIAGNOSTICS=1 "/Applications/GuluTwist Break Station.app/Contents/MacOS/gulu-twist"
   ```
   Windows PowerShell：
   ```powershell
   $env:GULU_DATA_DIR = "$env:LOCALAPPDATA\GuluTwist-eye-care-test"
   $env:GULU_DIAGNOSTICS = "1"
   & '实际路径\gulu-twist.exe'
   ```
4. 提醒日选择今天，工作时段覆盖当前时间。为加速验证，把五项间隔改为 5 分钟，护眼全屏时长保留 20 秒。启用胶囊。等待期间不要锁屏、睡眠或暂停，否则有效时间会冻结。
5. 记录自然到期的时刻；“体验 5 秒”不会生成正式完成记录，不能代替正式到期验证。

## Windows 原生构建

在 Windows 安装 Rust MSVC 工具链、Visual Studio 2022 Build Tools（C++ 桌面开发和 Windows SDK），进入仓库的本功能分支。建议使用 Developer PowerShell：

```powershell
git fetch origin
git switch feat/compact-floating-capsule
git pull --ff-only
cargo test --locked --workspace
.\scripts\package-windows.ps1 -SkipInstaller
```

产物为 `dist\GuluTwist-0.1.0-Windows-x64-portable.zip`。解压后运行 EXE。需要安装程序时另外安装 Inno Setup 6，去掉 `-SkipInstaller` 再执行打包脚本。若依赖或构建工具报错，保存完整错误信息；不能跳过错误后当作兼容通过。不要为测试向 `release` 分支推送，它会触发公开发包。

## 场景与预期

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| E01 新用户默认值 | 新数据目录首次启动，查看五项 | 四项轻提醒，护眼开启、20 分钟／20 秒全屏；各项均可选择模式 |
| E02 旧数据升级 | 先用旧版保存自定义间隔、关闭某项并产生记录，再退出用新包启动 | 原四项改轻提醒，间隔／开关／时长／历史不丢失；新增护眼默认开启 20／20；再次重启不覆盖自己新改的模式 |
| E03 混合到期 | 按准备步骤等待五分钟 | 仅护眼进入全屏，全部活动屏幕覆盖且退出可见；20 秒结束后恢复四条轻提醒，只新增护眼计时完成 |
| E04 持续待办 | 不处理四条，等待超过两分钟 | 条目不消失、不重复；主胶囊仍显示未来护眼倒计时 |
| E05 逐项完成 | 点击一个圆形勾选，再快速重复点 | 只移除该项，只记一次；该项恢复完整间隔，其余待办保留；按钮不误开主窗口或拖动 |
| E06 关闭胶囊 | 有待办时关闭悬浮窗开关 | 胶囊隐藏，独立提醒条仍在；逐个完成后全部隐藏，设置开关仍关闭 |
| E07 关闭状态到期 | 保持胶囊关闭，等待下一项到期 | 临时出现独立提醒条，完成后收起；常驻胶囊不擅自开启 |
| E08 护眼轻提醒 | 护眼选轻提醒保存，等待下一实例 | 出现眼睛图标条，无全屏；可以直接勾选；重启仍是轻提醒 |
| E09 其它项全屏 | 喝水设全屏 10 秒，护眼设全屏 20 秒，让两者从同一完整间隔开始 | 同批合并为 20 秒全屏，分别计时完成，其它轻提醒不被自动完成 |
| E10 当前实例不变 | 某项轻提醒待办存在时把该项改全屏 | 当前条目仍可勾选，不立即遮罩；下一实例使用全屏 |
| E11 暂停与恢复 | 有待办时手动暂停，再在当前时段恢复 | 暂停隐藏条目，恢复重现相同待办，不记完成、不新建重复项 |
| E12 锁屏与睡眠 | 有待办时锁屏／睡眠，在同一工作时段解锁 | 间隔冻结，待办重现；未来提醒遵守恢复缓冲 |
| E13 全屏中睡眠 | 护眼全屏开始后睡眠超过 20 秒，唤醒 | 原会话已到期则直接撤罩，只记一次护眼完成；旧轻提醒仍未被完成 |
| E14 午休／下班 | 提前设置一个几分钟后结束的工作时段，再等轻提醒到期且不处理 | 时段结束清空全部未完成，记录取消；下一时段从完整间隔开始，不补发 |
| E15 退出与重启 | 有待办时从托盘正常退出，再启动 | 所有提醒条／遮罩消失；旧待办不恢复，配置和历史保留 |
| E16 位置与屏幕 | 有多条时拖动胶囊到屏幕上方、底边、负坐标副屏；拔掉副屏 | 提醒条跟随；底部不足时翻到上方，勾选均可见；断屏后回到可用工作区 |
| E17 Windows DPI | 100%、125%、150%、200%，主副屏不同缩放 | 胶囊 200×52、条目 200×40 逻辑尺寸；圆角透明，无文字截断、白边或不可点击区域 |
| E18 焦点与退出 | 在其它应用输入，等待条目出现；打开胶囊菜单；全屏时按 Esc | 条目出现不抢焦点；菜单与条目不相互遮挡；任意全屏退出能同时撤掉全部遮罩 |
| E19 稍后／跳过 | 主窗口对待办选择稍后 5 分钟／跳过 | 稍后期间条目收起，到期同一实例回来；跳过移除且不算完成 |
| E20 全部待办／全部关闭 | 五项都设轻提醒并等待；随后关闭全部事项 | 全部待办时胶囊显示“全部待处理”；全部关闭后无待办，胶囊显示提醒未开启 |

## 结果记录

每台机器填写：应用文件名与 SHA-256、OS 版本、架构、显示器缩放、E01–E20 通过／失败／未测。失败时保存操作步骤、实际表现、预期、截图，以及测试目录日志；注明是否开启系统免打扰。不要把“未测”当作通过。

若出现无法退出的遮罩，先按 Esc 或点击紧急退出；仍异常时用系统任务管理器／强制退出结束应用并保留测试目录。本功能不应阻止系统退出路径。
