## 1. 背景、目标与范围

### 1.1 当前问题

1. 多个提醒事项同时计时，用户已经主动喝水或活动后，需要打开主窗口才能提前完成。胶囊只展示最近事项，无法直接选择其他正在计时的事项。
2. 工作时段使用普通文本框，用户需要自行输入时间分隔符；中文冒号、错误格式等会触发报错。
3. 间隔分钟、休息分钟和休息秒数使用普通文本框，非数字内容可以进入字段，之后才由校验阻止保存。
4. 全屏休息的“紧急退出本次休息”文案过长，且用户无法按个人偏好禁用这个提前结束入口。

代码核对依据：主窗口已有手动完成及重置单项间隔的能力；胶囊已有更多菜单和到期轻提醒条；项目锁定的 GPUI Kit 0.7.3 已包含 TimeField。以上是源码核对结果，不代表新交互已完成运行验证。

### 1.2 目标

| 编号 | 目标 | 验收口径 |
| --- | --- | --- |
| G-01 | 从胶囊快速选择任一正在进行的事项并完成 | 列表收起时，两次点击完成一项：打开清单、点击该项完成；无需打开主窗口 |
| G-02 | 同时看清所有活动事项的真实剩余时间 | 清单展示所有符合条件的事项，每项独立更新，剩余越少越靠近主胶囊，无重复行 |
| G-03 | 消除工作时间自由文本格式错误 | 使用小时／分钟分段的 TimeField，冒号由控件呈现，用户无需输入 |
| G-04 | 阻止非整数内容进入时长字段 | 键盘、输入法提交和粘贴均遵循数字规则，范围校验继续有效 |
| G-05 | 保留现有配置及提醒语义 | 完成只影响选中项；原有工作时段、全天配置、记录、暂停和全屏规则可回归验证 |
| G-06 | 简化全屏退出入口并允许用户配置 | 按钮只显示“退出”；默认可用，勾选“隐藏退出全屏按钮”并保存后不显示按钮，重启保留 |

### 1.3 本次范围

本次包含胶囊清单入口、活动事项列表、实时倒计时、逐项完成、与已有轻提醒条的协调、工作时间 TimeField 替换、三个时长字段的整数输入限制、全屏“退出”文案与可配置隐藏，以及相关验收。

面向现有桌面用户；目标平台沿用主 PRD：macOS 15+（Apple Silicon、Intel）及 Windows 10／11 x64。不同平台的运行验证结果必须分别记录。

## 3. 胶囊与事项清单

### 3.1 入口和视觉结构

**FR-L01：入口。** 在现有 `···` 左侧新增常驻清单图标；保留更多菜单功能。清单图标有“查看事项”的悬停提示和可访问名称，展开时有可辨识的选中状态。点击此图标不得完成事项、打开主窗口或触发拖动。

**FR-L02：结构。** 清单沿用参考图中的独立圆角胶囊行，每行包括事项图标、名称、剩余时间／状态和右侧圆形 `✓` 按钮。倒计时可以位于名称下方，以保证紧凑宽度下可读。示意中的秒数只作展示，不是默认配置：

```text
主胶囊： [小咕]  扭扭颈肩 / 04:42         [清单] [···]

清单：   [图标]  如厕放风 / 60:00                 [✓]
         [图标]  站立活动 / 35:00                 [✓]
         [图标]  咕嘟喝水 / 20:00                 [✓]
         [图标]  保护眼睛 / 12:00                 [✓]
         [图标]  扭扭颈肩 / 04:42                 [✓]
```

外观沿用当前浅／深色主题、绿色体系和两端半圆造型。主胶囊继续展示最近事项；清单展示全部活动事项，剩余时间越少的事项越靠近主胶囊。优先保持现有紧凑尺寸；主胶囊和清单的最终宽度需依据布局验证确定，不得因新增入口挤掉更多按钮或裁切 `240:00`。本需求不预先承诺新增按钮后仍能保持 200 像素宽度。

**FR-L03：开合。** 点击清单图标展开，再次点击、点击整组胶囊／清单以外区域、按 Esc 均收起。点击清单内的完成按钮不收起。清单与更多菜单互斥，打开其中一个时关闭另一个。拖动胶囊不因鼠标短暂移出而误关闭清单，展开内容随胶囊移动。

清单默认收起，展开状态不跨应用重启保存；胶囊开关与位置继续按已有规则保存。

### 3.2 清单范围与排序

**FR-L04：包含范围。** 正常工作状态下，清单包含以下已启用事项，每种事项最多一行：

| 事项状态 | 清单内容 | 完成操作 |
| --- | --- | --- |
| 正常等待下一次提醒 | 事项名称与剩余有效工作时间 | 可提前完成 |
| 稍后提醒中 | 名称、剩余稍后时间，并标注“稍后” | 可完成并取消本次稍后等待 |
| 已到期、尚未进入全屏会话 | 名称与“待完成”状态，不显示负倒计时 | 可完成；执行前重新核对当前状态 |
| 事项关闭 | 不出现在清单 | 不提供操作 |
| 已进入全屏休息／体验 | 整组胶囊和清单隐藏 | 不通过清单结束全屏休息 |

全屏方式的事项在等待到期时也属于清单范围，允许用户主动完成；一旦全屏会话已开始，沿用全屏休息规则。轻提醒／全屏配置不会因清单操作改变。

**FR-L05：靠近主胶囊排序。** 按引擎提供的实际剩余毫秒排序，剩余越少的事项越靠近主胶囊，不按显示字符串排序。清单向下展开时，从上到下由短到长；向上展开时，从上到下由长到短。展开方向变化后按新位置调整顺序。稍后项使用剩余稍后时间；待完成项以 0 参与排序，位于最靠近主胶囊的一侧。同值时从上到下保持固定顺序：喝水、颈肩、如厕放风、站立、护眼。

计时正常递减时相对顺序保持稳定；完成重置、稍后、设置变更或事项到期导致排序值变化时重新排序。屏幕上 `01:00` 与 `00:59` 的显示取整不能导致顺序抖动。

**FR-L06：实时显示。** 正常运行且清单可见时，每秒刷新倒计时；格式沿用分钟／秒，例如 `04:42`、`120:00`、`240:00`，不足一秒向上取整。清单、主胶囊和主窗口取同一个计时状态，不创建独立递减时钟。主窗口关闭后仍正常刷新。

### 3.3 完成、反馈和一致性

**FR-L07：逐项完成。** 只有点击对应行的 `✓` 才完成该事项，点击名称和倒计时不触发完成。按钮悬停提示“我已完成〈事项名称〉”，单击直接执行，不新增确认弹窗。

成功时：

1. 产生一次手动完成记录，与主窗口“我已完成”采用相同语义。
2. 清除该项当前的待完成或稍后状态，从完成时刻重新累计该项完整提醒间隔。
3. 其他事项的间隔、待办和历史记录不受影响。
4. 保留当前行并显示约 1 秒“已完成”反馈；下一轮已在完成时开始，反馈时长不得额外延后计时。
5. 反馈结束后显示下一轮剩余时间并按 FR-L05 重新排序，列表保持展开；主胶囊同步展示最新最近事项。

例：喝水间隔 30 分钟，当前剩余 `04:42`。用户完成喝水后，喝水进入新的 30 分钟周期，站立等其他事项继续原计时；清单中的喝水行可能因剩余时间变长而向上移动。

**FR-L08：防重复与过期操作。** 处理和反馈期间禁用该行完成按钮，同一手势、快速双击或同一轮的重复回调最多记一次完成。重新排序不能把尚未结束的鼠标手势落到另一事项的完成按钮。完成命令绑定事项及当前轮次／状态，不以行号定位。

若点击处理前该项已被主窗口完成、被关闭、跨过工作时段边界或进入全屏会话，刷新当前状态，不用旧操作再次完成新一轮。由等待转为同一轮的到期待办时，可完成该轮，但不得产生两条记录。执行失败须给出可见反馈；不能将失败显示为成功，也不能通过重复提交产生重复记录。持久化异常沿用现有错误处理和恢复路径。

### 3.4 与到期轻提醒条及全局状态的关系

**FR-L09：避免重复展示。** 清单收起时，已有到期轻提醒条按原规则展示，勾选后移除该条。清单展开时，由清单统一承载正在计时和待完成事项，原独立提醒条暂时不重复显示；这只改变展示，不删除待办。收起后，仍未完成的轻提醒条恢复；已完成的事项不恢复旧条目。

**FR-L10：状态切换。** 以下为细化默认，均不改变原有计时引擎规则：

| 全局场景 | 清单入口／列表行为 | 提醒及数据行为 |
| --- | --- | --- |
| 正常工作，有启用事项 | 入口可用，按需展开 | 显示活动事项 |
| 全部启用事项都已到期 | 入口仍可用，显示待完成项 | 允许逐项完成后进入下一轮 |
| 全局暂停或非工作时段 | 收起列表，入口禁用并提示原因 | 不通过清单恢复计时或新增完成记录 |
| 所有事项关闭 | 收起列表，入口禁用，提示“暂无开启的事项” | 不构造虚假倒计时 |
| 全屏休息、体验、锁屏／睡眠 | 收起并随胶囊隐藏；恢复后默认收起 | 保留／清空待办遵循已有工作时段规则 |
| 隐藏胶囊 | 一并关闭活动清单 | 到期独立轻提醒仍沿用已有行为，不重新开启胶囊 |
| 在设置中关闭某项 | 清单及时移除该项 | 不记完成 |
| 在设置中改变某项间隔 | 按引擎最新状态更新并重排 | 只应用现有设置生效规则 |
| 工作时段结束或退出应用 | 清单关闭，旧操作失效 | 不把清理待办记为完成 |
| 首次引导、恢复错误状态 | 不提供可执行的活动清单 | 沿用现有主窗口处理入口 |

**FR-L11：位置与焦点。** 默认在胶囊下方展开；空间不足时整组翻到上方，向上展开也保持从上到下剩余时间递减。校正屏幕边缘，五项均可访问；小工作区无法一次容纳时允许清单内部滚动。跨屏、不同缩放比例及拖动后不得落在不可见区域。

用户主动打开列表后可以键盘操作；后台倒计时更新和新到期状态不抢夺其他应用焦点。清单入口和完成按钮具有独立点击区域，不触发胶囊拖动或双击打开主窗口。Tab 可访问按钮，Enter／Space 执行，Esc 收起；读屏名称包含事项及动作，倒计时不得每秒主动播报。

## 4. 工作时间 TimeField

**FR-T01：组件与范围。** 首次引导及提醒设置中的所有工作时段开始／结束字段，使用 GPUI Kit `TimeField`，默认 24 小时制、分钟精度，展示 `HH:MM`；不显示秒、AM／PM，也不另建弹出时间选择面板。

**FR-T02：编辑行为。** 小时、分钟分别选择和编辑，冒号为固定分隔符。支持数字输入、上下键调整选中分段、左右键及 Tab／Shift-Tab 切换，位数和字段宽度保持稳定。退格／删除遵循组件分段重置行为，不退化成任意文本框。

用户不需要输入英文或中文冒号。中文、字母、冒号等不能作为自由文本写入时间值。本版不要求整段 `09：30` 文本的粘贴解析；对组件未支持的整段粘贴应忽略并保持原值，不能误读为另一个时间。这一规则替代前期普通文本方案中“规范化中文冒号粘贴”的建议。

**FR-T03：日内值与当天结束。** TimeField 的小时范围为 `00–23`、分钟为 `00–59`；原配置允许结束时间 `24:00`，必须保留该能力。

细化默认采用结束字段旁的“至当天结束”勾选项：

- 未勾选：使用 TimeField 编辑普通日内结束时间。
- 勾选：结束值为当天 `24:00`；以明确文字“24:00（当天结束）”替代可编辑的结束 TimeField，开始时间继续可编辑。
- 取消勾选：恢复当前编辑会话中最近一次普通结束时间；若载入的配置原本就是 `24:00` 且没有该草稿值，则使用 `23:59` 并正常校验。
- 开始时间不提供“至当天结束”，范围为 `00:00–23:59`。
- 保存后仍用原有当天分钟值表示，结束 `24:00` 对应 1440，不能保存成当天 `00:00` 或擅自改成 `23:59`。
- 载入已有 `00:00–24:00` 配置时，正确勾选并完整显示；不修改设置直接保存，不改变覆盖时间。

**FR-T04：业务校验。** 保留现有 1–4 个时段、至少一个工作日、结束晚于开始、不重叠、相邻时段保存时合并、跨午夜需拆成两段的规则。组件负责输入格式，业务校验负责时段合法性；两个时段分别可输入不代表组合一定有效。

**FR-T05：错误和草稿。** 编辑分段过程中不因暂时输入第一位数字弹出自由文本格式错误。离开字段／相关勾选项或尝试保存时，显示具体时段错误；非法草稿不得保存。取消、重置、导航时的未保存保护及保存失败保留草稿，沿用设置页行为。单纯聚焦、切换分段不应把未修改的设置标记为已修改。

## 5. 间隔和休息时长整数输入

**FR-N01：覆盖字段。** 五类提醒的间隔分钟、全屏休息分钟和全屏休息秒数统一采用非负整数输入规则，涵盖首次引导和设置页。停用事项的字段继续禁用；切换为轻提醒时保留原休息时长。

**FR-N02：输入限制。** 允许半角数字 `0–9`。字母、汉字、全角数字、小数点、正负号、指数形式、空格及其他符号不能进入已提交的字段值。输入法组合过程中不打断系统候选操作，提交非数字内容时拒绝；正常光标移动、选中、删除和复制操作仍可用。

粘贴采用整段判断：仅由数字组成的内容可粘贴，包含任一非法字符时整次拒绝，保留原值并提示“仅支持数字”。不得过滤部分字符后改变含义，例如不能将 `1.5` 变成 `15`、`-5` 变成 `5`、`20分钟` 变成 `20`。

**FR-N03：编辑态与取值范围。** 允许临时清空以便重新输入；空值不能保存。允许先输入不完整或越界的数字草稿，例如输入 `20` 过程中的 `2`，不在每次按键后强制钳制为最小值。失焦或保存时进行数值校验，越界时提示，不自动改成边界值。

| 字段 | 保存时允许范围 | 示例 |
| --- | --- | --- |
| 间隔分钟 | 整数 5–240 | 5、20、240 合法；0、4、241 非法 |
| 休息分钟 | 非负整数 0–30，另校验合计时长 | 0 分 20 秒合法；30 分 1 秒非法 |
| 休息秒数 | 整数 0–59，另校验合计时长 | 1 分 0 秒合法；0 分 60 秒非法 |
| 合计休息时长 | 5–1800 秒，即 5 秒–30 分钟 | 0 分 4 秒非法；0 分 5 秒、30 分 0 秒合法 |

允许输入前导零，完成编辑时统一为普通整数显示，例如 `020 → 20`。超长数字必须安全拒绝保存或在输入层限制长度，不得溢出、崩溃或截断成另一个可保存值。

**FR-N04：错误位置与保存。** 在对应事项／字段附近显示“间隔须为 5–240 分钟”“秒数须为 0–59”或“休息时长须为 5 秒–30 分钟”等可操作提示。任何非法字段都不能更新正式设置或影响正在运行的计时。保存成功、取消、切换提醒方式及未保存保护遵循现有规则。

## 6. 全屏休息退出设置

### 6.1 按钮文案与设置入口

**FR-E01：统一文案。** 所有全屏休息遮罩底部的退出按钮，可见文案统一为“退出”，不再显示“紧急退出本次休息”。正式休息、体验遮罩以及多显示器上的同一入口均使用新文案。可访问名称可以使用“退出全屏休息”，明确其只结束本次休息，与菜单中的退出应用区分。

未隐藏时沿用现有灰色文字、下划线及悬停手形样式；单击直接生效，不增加确认弹窗。任一显示器点击后，整场休息的所有遮罩关闭；正式休息只记录一次中断，不记完成，不退出后台应用；体验不写正式记录。

**FR-E02：全局设置。** 在“提醒设置”页面新增“全屏休息”分组，包含一个复选框，标签严格为“隐藏退出全屏按钮”。细化默认采用全局配置，统一作用于所有选择全屏方式的事项及合并休息会话，不按事项分别设置；轻提醒不受影响。

| 复选框状态 | 全屏按钮 | 用户操作结果 |
| --- | --- | --- |
| 不勾选，默认 | 显示“退出”，可操作 | 单击结束本次休息 |
| 勾选并保存 | 不显示退出按钮及底部操作区域 | 无按钮可点击或聚焦，旧回调也不能提前结束 |

辅助说明：“勾选后，全屏休息中不显示‘退出’按钮，倒计时结束后自动关闭。”

### 6.2 隐藏效果、生效时机与持久化

**FR-E03：实际隐藏。** 勾选生效后，所有显示器均不渲染退出按钮及其底部操作区域，按钮不进入键盘焦点顺序或可访问树。对应的本次休息手动中断操作仍检查权限，迟到的按钮回调不能绕过限制。

Esc、返回键及关闭窗口快捷键继续按现有规则不结束全屏休息；不新增替代性的结束本次休息快捷入口。倒计时正常结束后自动撤下整组遮罩，正式休息按原规则记录计时完成。全局暂停、退出应用、工作时段结束和故障清理仍遵循既有生命周期规则，本选项的作用范围是禁用全屏界面的提前退出操作。

**FR-E04：生效时机。** 配置遵循设置页的保存／取消和未保存保护机制：勾选草稿不会立即影响运行状态，保存成功后对下一次启动的全屏休息生效。每场休息开始时固定本场退出权限；即使后续配置发生变化，也不在同一场休息中途改变按钮权限。保存这个选项本身不得重置提醒间隔、清空待办或新增记录。

正式休息与体验遮罩均遵循已保存配置，体验仍按其原有短倒计时自动结束、不计正式记录。未保存的复选框草稿不用于体验。取消勾选并保存后，下一场全屏休息恢复可退出。

**FR-E05：默认值与兼容。** 新用户默认不勾选，允许退出；已有配置缺少此项时也按未勾选读取，不改变旧用户的默认体验。用户保存后的选择跨应用重启保留。保存失败时提示错误并保留可编辑草稿，运行时继续使用最近一次成功保存的配置。恢复默认设置时回到未勾选状态。

**FR-E06：关联说明与异常处理。** 设置页、关于页、遮罩提示和可访问描述须同步调整，不再无条件宣称“任何时候都可以紧急退出”或“全屏休息始终可以紧急退出”。允许退出时可提示“可点击底部‘退出’结束本次休息”；隐藏时改为“退出按钮已隐藏，休息结束后自动关闭”。

禁用退出是有效配置，不得被当作“退出路径故障”而自动降级为轻提醒。真正的窗口创建、显示或计时故障仍按既有规则清理与降级，不得留下残留遮罩。本节取代主 PRD 中无条件保留全屏退出入口、旧按钮文案，以及体验遮罩始终可手动退出的要求；其他休息计时和记录规则沿用。

### 9.2 性能与兼容

- TimeField 原生范围不包含 `24:00`，必须由 FR-T03 的明确界面状态处理，不能仅靠格式化掩盖值的变化。
- 图标及资源随应用打包；主窗口关闭、冷启动和托盘常驻行为继续通过回归。

### 9.3 质量门禁和证据

实现后执行 `./scripts/check.sh`，增加或调整能覆盖排序、状态切换、完成去重、全天时间映射、输入边界、全屏退出权限及旧配置默认值的必要验证。原生交互按 US／AT 编号记录实际操作、预期、结果和证据。

本机验证、Windows 目标机验证和 Intel Mac 实机验证分别记录；编译通过不能代替窗口行为验证。优先覆盖深浅主题、100%／150%／200% 缩放、三位分钟、屏幕边缘、主窗口关闭及输入法编辑场景。本次实施的自动检查、本机交互与外机待测范围见交付报告。

## 10. 非目标

- 胶囊上一键完成当前事项、全部完成、批量选择或自动完成。
- 新增自定义任务、排序设置、拖动调整清单顺序、跨设备同步。
- 在清单中增加稍后、跳过、编辑提醒配置等第二套完整管理界面；原入口保留。
- 清单操作绕过已开始的全屏休息，或更改暂停、锁屏、恢复缓冲和工作时段计时规则。
- 新增独立时间选择面板、自然语言时间解析、跨午夜单时段或整段时间文本粘贴解析。
- 调整默认提醒间隔、数值上下限、提醒方式和历史记录规则。
- 将全屏退出选项拆成逐事项配置，或借此禁用系统快捷键、全局暂停及退出应用。
